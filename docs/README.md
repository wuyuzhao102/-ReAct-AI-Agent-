## 写文档的约定

1. 一个文档一个主题，文件名用 `数字-中文名.md`，方便排序。
2. 文档开头写**最后更新时间**和**负责人**。
3. 图片放 `docs/assets/`，命名用英文小写加连字符，例如 `architecture-overview.png`。
4. 改公共文档（如本索引、协作规范）前先在群里说一声，避免冲突。
