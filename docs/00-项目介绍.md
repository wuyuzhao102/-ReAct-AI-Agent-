## 一、项目概述

本项目是面向在校大学生的 **Web 智能学习平台**，属于软件工程课程设计项目。

系统采用 **前后端分离 + Java/Python 双服务架构**，核心使用 **ReAct AI 智能体（Agent）**。区别于普通一次性问答的大模型，ReAct 智能体按照「**Thought 思考 → Action 行动 → Observation 观察**」循环，自主判断任务、调用外部工具，读取学生上传的 PDF / Word 课程课件，基于课件原文生成复习资料、练习题与学习计划，从而降低大模型的知识幻觉。

学生可以在网页上上传讲义、与 AI 对话、保存错题与笔记，辅助课程备考。

---

## 二、项目背景

当前很多学生会用大模型辅助复习，但存在明显缺陷：

1. 大模型依靠预训练知识回答，**容易编造知识点（知识幻觉）**，答案和课堂课件不一致；
2. 面对复杂备考任务，**不会自动拆分多步骤工作**；
3. **无法读取自己的课程 PDF 讲义**，也不能记录个人错题、薄弱知识点。

因此我们开发本平台，将 AI Agent 技术结合课程学习场景，让 AI 基于学生自己上传的课件进行作答，实现个性化课程复习。

---

## 三、项目目标

1. 搭建 ReAct 智能体，能够理解自然语言学习需求，自动拆分任务、调用工具完成多步学习任务。
2. 支持上传 PDF、Word 课件，提取文档文本，检索课件内知识点。
3. 实现智能对话，支持生成复习提纲、配套习题、个性化备考计划。
4. 提供个人学习档案，自动保存笔记、错题、历史对话记录。
5. 开发网页交互界面，实现用户登录、课件管理、对话交互。
6. 遵循软件工程开发流程，完成需求、设计、编码、测试，产出全套项目文档。

## 四、系统功能

### 1. 用户管理模块

用户注册、登录、密码管理，区分不同用户的数据 —— 课件、笔记**只对本人可见**。

### 2. 课件资源管理模块

上传 PDF / Word 课件；解析提取文档文字，建立文本索引；课件列表查看、删除。

> **限制**：基础版本只支持文档内文字，**不能识别图片中的文字与图片公式**。图片识别作为后续扩展功能。

### 3. AI Agent 智能对话模块（核心亮点）

用户输入自然语言学习请求，ReAct 智能体循环执行「思考 → 调用工具 → 获取结果」；内置 4 个工具：

| 工具 | 作用 |
| :--- | :--- |
| 🔍 课件检索工具 | 在用户上传的课件文本索引中检索相关知识点 |
| 📝 习题生成工具 | 基于检索到的课件内容生成配套练习题与解析 |
| 📅 学习计划生成工具 | 根据考试时间与薄弱点排布备考计划 |
| 🗂️ 笔记归档工具 | 把本次产出的资料保存到个人学习档案 |

输出内容为 **Markdown 格式**，前端渲染富文本，支持标题、列表、**数学公式**展示。

### 4. 个人学习档案模块

保存历史对话、AI 生成笔记、错题记录，学生随时回看复习资料。

## 五、技术栈

整体架构：**前后端分离**，双服务通过 HTTP 通信。

| # | 层 | 技术 | 职责 |
| :-: | :--- | :--- | :--- |
| 1 | 前端 | **Vue3 + Element Plus** | 网页页面：登录页、课件上传页、AI 对话页、学习档案页；集成 Markdown 渲染组件，展示公式与富文本 |
| 2 | Java 业务服务 | **Spring Boot + MySQL** | 业务逻辑，接收前端请求，用户管理、文件存储、数据库读写；作为中间层，通过 HTTP 调用 Python Agent 服务，转发请求、接收结果 |
| 3 | Python 智能体服务 | **LangChain + FastAPI + PyPDF** | LangChain 实现 ReAct Agent，管理 Thought-Action-Observation 循环；FastAPI 把 Agent 封装成 HTTP 接口；PyPDF 解析 PDF 文本；对接大模型 API（DeepSeek / 通义千问）做推理 |
| 4 | 数据库 | **MySQL** | 存储用户信息、课件索引、对话记录、笔记、错题 |
| 5 | 版本协同 | **GitHub** | 多人协作开发，分支管理，代码提交与评审 |

## 六、核心原理：ReAct Agent 循环

ReAct 即 **Reason（推理思考）+ Act（行动）**，循环执行三步：

1. **Thought**：智能体分析需求，判断下一步操作，决定调用哪个工具；
2. **Action**：调用预先编写好的工具函数，执行操作；
3. **Observation**：接收工具返回结果，作为下一轮思考依据。

### 使用示例

**用户操作**：登录系统，上传《高等数学.pdf》，在对话框输入「下周要考高数极限，帮我复习」

| 步 | 环节 | 内容 |
| :-: | :--- | :--- |
| 1 | Thought | 用户需要极限备考，先检索课件获取极限知识点，再生成复习提纲和习题，完成后归档笔记 |
| 2 | Action | 调用课件检索工具，检索关键词「极限」 |
| 3 | Observation | 返回课件原文：极限定义、两个重要极限、洛必达法则、等价无穷小替换和课堂例题 |
| 4 | Thought | 知识点已获取，基于课件内容生成复习提纲和 3 道配套练习题 |
| 5 | Action | 调用习题生成工具 |
| 6 | Observation | 返回复习提纲、3 道极限计算题 + 详细解题步骤 |
| 7 | Thought | 所有任务完成，将本次资料保存到用户学习档案 |
| 8 | Action | 调用笔记归档工具，存入数据库 |
| 9 | Observation | 归档成功 |

网页将 Markdown 内容渲染展示，用户可以在学习档案页面回看这份资料。

## 八、项目难点与解决方案

| # | 难点 | 解决方案 |
| :-: | :--- | :--- |
| 1 | 大模型知识幻觉 | 强制 Agent 优先检索用户上传课件，基于课件原文作答，减少凭空编造知识点 |
| 2 | Agent 无限循环调用工具 | 设置最大循环次数，增加任务完成判断条件，防止死循环 |
| 3 | PDF 文本提取乱码 | 使用 PyPDF 提取文本，过滤无效换行与特殊符号，清洗文本 |

## 九、项目不足与未来扩展

### 现存不足

1. 仅支持 PDF、Word 文本提取，不能识别图片、扫描版课件里的公式文字。
2. Agent 面对超复杂长任务的规划能力有限，适合课程复习这类中等复杂度任务。
3. 依赖第三方大模型 API，网络波动会影响系统响应。

### 未来扩展方向

1. 接入 OCR（PaddleOCR），识别图片、手写公式，支持扫描课件。
2. 升级为多智能体 **Multi-Agent**，多个 Agent 分工协作（检索 Agent、批改 Agent）。
3. 增加代码习题批改功能，适配计算机专业课程复习。

---

## 十、项目总结

本项目基于 ReAct AI Agent，将智能体工具调用能力应用于校园课程复习场景。系统使用前后端分离、Java + Python 双服务架构，让 AI 依托学生上传的课件完成复习任务，解决普通大模型容易产生幻觉的问题，为大学生课程备考提供智能化辅助，同时完整实践软件工程整套开发流程。
